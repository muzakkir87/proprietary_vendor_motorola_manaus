# Motorola Edge 40 Neo — Vendor Build Notes

Proprietary vendor files for the Motorola Edge 40 Neo (`manaus`), based on the MediaTek MT6879 platform.

## Device Information

- **Manufacturer:** Motorola
- **Device:** Motorola Edge 40 Neo
- **Codename:** `manaus`
- **SoC:** MediaTek MT6879
- **Source branch:** `lineage-23.2`

## Related Repositories

## Build Context

This vendor repository revision was used in the source configuration for a successful unofficial Evolution X 16.0 compilation for the Motorola Edge 40 Neo on 17 October 2026.

Compilation success does not establish that all device features work correctly.
